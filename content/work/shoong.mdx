## 팬 활동의 여러 순간을 하나의 흐름으로

Shoong!은 포토카드를 교환하고 생일카페 정보를 찾는 팬 활동을 하나의 웹 경험으로 연결한 프로젝트입니다. 흩어진 정보를 탐색하는 과정과 교환 상대를 찾는 과정을 더 명료하게 만드는 데 초점을 맞췄습니다.

## 구현에서 집중한 부분

- 작은 화면에서도 탐색 흐름이 끊기지 않는 반응형 UI
- 교환과 장소 정보처럼 성격이 다른 콘텐츠의 시각적 위계
- 사용자가 다음 행동을 빠르게 판단할 수 있는 카드와 상세 구조
- 상태가 많은 화면을 예측 가능한 방식으로 관리하는 프론트엔드 구조

## 이 프로젝트가 보여주는 것

사용자의 취미와 감정이 연결된 서비스를 다룰 때, 기능의 수보다 맥락을 놓치지 않는 인터페이스가 중요하다는 것을 배웠습니다. 제품의 언어와 상호작용을 함께 다듬은 경험입니다.
