# 외주 프로젝트 2건 포트폴리오 반영 계획

작성일: 2026-10-20

상태: 계획에 따른 사이트 코드 구현 및 로컬 검증 완료. 운영 배포 전.

## 목표와 소개 문구

꼼꼼환경과 강사 프로필 + CMS를 실제 외주 결과물로 추가한다. 소개는 **고객이 받는 결과물 → 직접 맡는 범위 → 구현 사례 → 제작 정보** 순서로 쓴다. ‘2주간 전 과정을 1인으로’는 꼼꼼환경의 제작 정보에 배치하고, 첫 문장은 완성된 상담 흐름을 설명한다.

공통 소개안:

> 고객에게 필요한 웹사이트와 업무 도구를 만듭니다. 화면과 서버 기능, 콘텐츠 관리와 배포를 연결하고, 공개 이후의 개선까지 함께합니다.

기존 AI 활용 교육·멘토링 소개와 6장 홈 구조는 유지한다. 외주 개발 범위를 프론트엔드에 한정하지 않되 과거 팀 프로젝트의 담당 역할은 그대로 둔다.

## 상세 페이지와 시각 방향

각 상세를 **고객의 필요 → 제공한 결과 → 핵심 기능·결정 → 검증·운영**으로 구성한다. 꼼꼼환경에는 1인·2주를 제작 정보로, 강사 CMS에는 콘텐츠를 직접 관리하는 흐름을 중심으로 담는다.

현재 승인된 디자인을 유지한다. 색은 기본 배경 `#f0efe9`, 표면 `#f7f6f1`, 본문 `#191b20`, 청색 `#294bd8`, 녹색 `#517329`, 주황색 `#b74521`을 기존 테마 토큰으로 사용한다. 기존 Pretendard 본문·대제목과 모노 메타데이터 역할을 유지한다. 새 애니메이션·라이브러리는 추가하지 않는다.

차별점은 **실제 납품 화면을 설명과 함께 보여주는 화면 아카이브**다. 상세 페이지에 공개 화면 2장씩, 한/영 대체 텍스트와 캡션·원본 크게 보기를 제공한다. 넓은 화면은 2열, 모바일은 1열로 읽는다. 이미지 크기를 명시해 공간을 예약하고 Next Image로 제공한다. 관리자 화면을 임의로 재현하지 않으며, 계정·비밀값·실제 접수 개인정보는 캡처하지 않는다.

UI 지침은 `frontend-ui-workflow`와 하위 디자인·UX 스킬을 적용했다. 검색 결과의 일반 팔레트보다 기존 승인 팔레트를 우선하고, 이미지 공간 예약·반응형·키보드 포커스·대비 지침을 적용한다.

## 실행과 검증

1. 이 계획을 기준으로 한국어 사례·영문 대응 문구와 공개 화면을 준비한다.
2. 기존 사용자 변경을 보존하면서 두 항목과 공통 표시를 구현한다. 원본 외주 프로젝트는 수정하지 않는다.
3. typecheck·관련 lint·production build를 수행한다. 현재 `lint` 스크립트가 실행 불가하면 원인을 구분하고 설치된 ESLint의 직접 실행으로 변경 파일을 검사한다.
4. 한/영 홈·Work 목록·신규 상세 4개·이력서·사이트맵을 확인한다. 실제 브라우저에서 데스크톱·모바일, 기본/야간, 언어 이동·외부 링크·이미지 표시·키보드 포커스를 확인한다.
5. 소스·문구·검증 결과를 다시 대조하고 현재 범위의 결과를 보고한다. 커밋·푸시·배포는 이번 요청에 포함하지 않는다.

## 사실과 남은 제한

- 꼼꼼환경은 기존 두 채팅·소스·운영 화면, 강사 CMS는 「강사 프로필 CMS 구현 계획 수립」 채팅·현재 원본 소스·공개 데모를 대조한다.
- 강사 CMS 현재 원본 위치는 `/Users/fullkeem/외주/프로필 사이트/instructor-profile-cms`이며 채팅의 예전 작업 폴더와 다르다.
- 전환율·매출·검색 순위·문의 증가·CMS 절약 시간은 검증된 수치가 없어 사용하지 않는다.
- 강사 프로젝트의 팀 인원·제작 기간은 미확정이므로 수치 표기하지 않는다. 구현을 막는 필수 정보는 아니다.
- 계획과 최종 코드가 달라지면 완료 시 이 문서를 실제 구현과 맞춘다.

## 구현 결과와 검증 기록

- 한국어 사례 2개와 영문 대응 본문·제목을 등록했다. Work는 기존 5개에서 7개로 늘었고 새 외주 사례를 맨 앞에 배치했다.
- 홈 소개·개발 범위·작업 안내와 공유 프로필 소개를 고객 결과 중심으로 수정했다. 기존 역할 헤더·6장 구성·테마 전환은 유지했다.
- 실제 공개 화면 4장을 1440×1000 WebP로 저장했다. 원본 이미지 파일 합계는 약 174KiB이며, 상세에서 한/영 설명·캡션과 원본 크게 보기를 제공한다.
- 꼼꼼환경에는 제작 2주·1인 담당 정보를 별도 표시한다. CMS는 공개 데모로 구분하고 두 사례 모두 비공개 GitHub 링크는 표시하지 않는다.
- `pnpm type-check` 통과, `pnpm lint` 경고·오류 없음, 최종 `pnpm build` 통과. 빌드가 정적 페이지 31개와 신규 한/영 상세 4개를 생성했다. 기존 Browserslist 데이터 갱신 안내는 빌드를 막지 않았다.
- 실제 Chromium에서 신규 상세 4개 × 데스크톱 1440px·모바일 390px × 기본·야간 16개 조합을 확인했다. 각 페이지 200 응답, 이미지 로드·대체 텍스트·본문·공개 데모 라벨 정상, 가로 넘침·런타임 오류 없음.
- 한/영 홈·Work·이력서의 데스크톱·모바일 12개 조합을 확인했다. 항목 수·정렬·신규 이력서 항목이 정상 반영됐으며 가로 넘침이 없었다.
- 홈 → Work → 사례 → 목록 복귀, 언어 변경 중 야간 모드 유지, 실제 Tab 이동 시 2px 포커스 표시, Enter로 원본 이미지 새 창 열기를 확인했다. 사이트맵의 신규 경로 4개와 유효한 날짜도 확인했다.
- 독립 검토에서 새 외주 분류의 스크린리더 누락을 찾아 카드 본문에 접근 가능한 안내를 추가했다. 긴 새 제목에는 단어 단위 줄바꿈과 균형 배치를 적용했다.
- 검증용 화면은 `output/client-projects-20261020/`에 보관한다. 이번 작업에서 외주 원본 프로젝트의 재배포·관리자 변경·실문의 발송, 포트폴리오 커밋·푸시·운영 배포는 수행하지 않았다.
