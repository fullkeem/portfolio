# 포트폴리오 기본 / 야간 모드

승인된 SVG 시안을 기준으로 홈(`/`, `/en`)의 6장 슬라이드를 수정했다. Work 아카이브·프로젝트 상세·Resume·Writing 목록과 상세에도 같은 팔레트와 전환을 적용한다. 공통 헤더에서 언제든 모드를 바꾸며 페이지·언어 이동 중에도 선택을 유지한다.

## 디자인과 동작

- 한국어 버튼: `기본 / 야간`. 영어 버튼: `Light / Dark`.
- 첫 방문은 기본 모드. `fullkeem-theme`에 선택을 저장하고 첫 페인트 전에 복원한다. 저장소 접근이 막혀도 현재 페이지에서 모드를 변경할 수 있다.
- 배경·본문·테두리·강조색·발광·버튼 표시가 하나의 `--theme-progress`를 공유한다. 520ms, `cubic-bezier(.4,0,.2,1)`로 전환하며, 연속 클릭 시 현재 진행값에서 반대로 이어진다.
- 모션 줄이기 설정에서는 즉시 변경한다. `@property`를 지원하지 않는 구형 브라우저에서도 최종 테마는 적용되지만 연속 보간은 제공되지 않는다.
- 01·02·05·06은 중립 배경과 색상 강조 제목. 03·04는 기존 색면 구조를 유지하고 명도만 조정한다. 사진과 프로필 인사 동작은 유지한다.
- 작은 화면에서는 슬라이드 내부를 세로로 읽을 수 있다. 세로로 넘치는 슬라이드에서 휠을 사용하면 내용을 스크롤하며, 버튼·가로 스와이프로 다른 슬라이드로 이동한다.

| 용도 | 기본 | 야간 |
| --- | --- | --- |
| 배경 / 표면 | `#f0efe9` / `#f7f6f1` | `#111316` / `#171a1f` |
| 본문 / 보조 글자 | `#191b20` / `#65686f` | `#f0f0e9` / `#a8adb8` |
| 청색 강조 | `#294bd8` | `#8eaaff` |
| 주황 강조 | `#b74521` | `#ff9c74` |
| 녹색 강조 | `#517329` | `#caed88` |
| 색면 청색 | `#294bd8` | `#223984` |

## 콘텐츠 페이지

- 기존 배치와 내용을 유지하고 색면을 중립 표면으로 전환한다. Work는 프로젝트별 청색·녹색·주황색, Writing은 녹색, Resume는 청색을 사용한다.
- 큰 제목과 프로젝트 카드 제목만 은은하게 발광한다. 본문과 메타 정보에는 발광을 적용하지 않는다.
- 인쇄에서는 밝은 배경과 검은 글자, 발광 없는 이력서를 출력한다.

## 콘텐츠 판단

역할 표시는 `Developer, AX Tutor/Mentor`로 축약했다. PBL·해커톤을 AX와 동의어로 취급하지 않고 실제 활동 설명에 남겼다. 과거 프로젝트의 프론트엔드 담당 기록은 변경하지 않았다.

| 섹션 | 기존 문제 | 반영한 방향 |
| --- | --- | --- |
| Intro | 긴 직함과 추상적인 인물 소개 | ‘아이디어를 구현하다.’, 개발과 AI 교육이라는 두 역할 |
| Position | ‘대신 만들지 않는다’와 직접 개발한다는 설명의 충돌 | 제품 개발과 AI 활용 교육을 구분 |
| Practice | 역할 설명의 반복 | 제품 개발 / AI 업무 적용 / 교육·멘토링 |
| Method | 단계별 결과물이 불명확 | 문제 정의문, 사용자 흐름, 데이터 구조, 우선순위, 배포·시연 |
| Explore | 상세 페이지가 있다는 안내에 머묾 | 서울렛·Shoong!과 담당 역할, SEO·AEO·GEO 글을 구체적으로 안내 |
| Contact | 문의 유형의 우선순위가 불명확 | 개발과 교육을 주요 문의로, 채용·기타 협업을 보조 문의로 배치 |

프로젝트명·담당 역할은 기존 콘텐츠를 사용했다. 교육 성과 수치·수강 인원·후기는 검증된 자료가 없어 추가하지 않았다.

## 근거와 검증 기준

- 간결하고 훑어보기 쉬운 설명: [Nielsen Norman Group](https://www.nngroup.com/articles/concise-scannable-and-objective-how-to-write-for-the-web/).
- 주장에 실제 결과물과 확인 가능한 근거 연결: [Stanford 웹 신뢰성 가이드](https://credibility.stanford.edu/guidelines/index.html).
- 본문 4.5:1, 큰 글자 3:1 대비: [WCAG 2.2](https://www.w3.org/TR/WCAG22/). 표면색 기준 본문 대비는 기본 15.92:1 / 야간 15.24:1, 보조 글자는 5.16:1 / 7.75:1이다. 색면의 보조 글자도 최소 4.81:1이다. 발광을 대비 근거에 포함하지 않는다.
- 야간 모드를 가독성 개선으로 단정하지 않는다: [Piepenbrock 외, 2014](https://pubmed.ncbi.nlm.nih.gov/25141597/). 이 연구의 교정 과제 결과를 문의 전환율이나 디자인 선호도에 일반화하지 않는다.
- 공유 색상 보간: [MDN @property](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40property).

회귀 확인 대상은 두 언어의 6개 슬라이드, 데스크톱·모바일·작은 화면, 저장·새로고침·언어 전환, 전환 중 반대 모드 선택, 키보드·휠·스와이프, 프로필 인사, 상세 페이지 왕복이다. 저장소 초기화는 미설정·기본·야간·잘못된 값·접근 거부를 확인한다.
