## 1. 기존 사이트를 이력서 겸 포트폴리오로 전환 — 2026-08-13~08-16

사용자는 기존 프론트엔드 PR·외주 사이트에 AX 개발, 기업교육 보조강사, PBL·해커톤 멘토 활동까지 담으려 했다. 단조로운 구성을 바꾸고 개인의 특성이 드러나는 디자인을 원했다. 당시 공유 주소는 [GitHub 저장소](https://github.com/fullkeem/portfolio)와 [기존 Vercel 사이트](https://portfolio-fullkeems-projects.vercel.app/)였다. 링크의 현재 배포 상태는 이번에 재검증하지 않았다.

- Pinterest 레퍼런스로 힙하고 트렌디한 홈을 요청했다. 강한 스크롤 타이포그래피와 텍스트를 보기 위해 끝없이 스크롤하는 구성은 피하고 싶다고 명시했다.
- Vue + Vite 전환 및 React + Next.js 대 Vue + Nuxt 비교를 논의했으나, 최종적으로 **React + Next.js 유지**를 선택했다.
- 작업 전 Git 연결 확인에서 로컬 `.git`이 없음을 발견했다. 기존 폴더 백업 후 GitHub `develop`을 다시 복제하는 절차를 안내했고, 사용자의 설정 완료 후 정상 연결을 확인했다.
- 백업과의 비교 중 보인 `.git/HEAD`, `.git/config` 차이는 Git 연결 정보 차이라고 설명했다. 터미널 pager 종료 방법과 생성 파일을 제외한 비교법도 안내했다. 백업의 현재 존속 여부는 이번 조사 범위가 아니다.
- **2026-08-14 새벽:** 코발트 에디토리얼 스타일의 홈, Work·Resume·Writing, 인쇄 가능한 이력서, MDX 콘텐츠, SEO·공유 이미지·사이트맵·옛 주소 리다이렉트를 구현했다.
- Notion, Supabase, 댓글, 이미지 프록시와 불필요한 애니메이션 의존성을 제거했다. Next.js는 당시 작업에서 15.5.23으로 변경했다.
- 당시 lint·타입 검사·빌드, 1440×900·390×844, 주요 콘솔 오류·넘침·리다이렉트 검증 성공을 보고했다. Browserslist 갱신 안내가 남아 있었다.
- 사용자의 로컬 서버 실행·종료 요청을 처리했다. 그때의 실행 상태를 현재 상태로 간주하지 않는다.
- 사용자 제공 ZEN SERIF TTF를 WOFF2로 변환하고 OTF·TTF 원본을 보존했다. 당시 Georgia 사용 영역에 적용하고 타입·빌드·브라우저 확인을 했다.

**당시 콘텐츠 평가:** 시각적 개성과 구조에 비해 실제 사례·기여·활동 기간·성과 근거가 부족하다고 진단했다. 당시의 평가 점수, 글자 크기, 번들 크기는 그 버전의 관찰이며 현재 수치가 아니다. 특히 “Work 이미지 0장”이라는 옛 진단은 10월 외주 갤러리 추가로 일부 해소되었다.

**멘토링 역할 정리:** 사용자는 기획·개발 흐름·데이터 구성·배포를 조언한 경험이라고 설명했다. 이에 직접 구현과 조언을 구분하는 사례 서술, 문제 → 관여 범위 → 주요 결정 → 팀 구현 → 결과 구조를 제안했다. 예시의 인원·기간·성과는 실제 이력이 아니라 예시이며 사실로 전용하지 않는다.

기존 5개 프로젝트는 오래되었다는 이유만으로 모두 삭제하지 않고, 현재 수주 목적과의 관련성·기여 설명·화면 완성도·실제 결과물을 기준으로 선별하자는 제안이 나왔다. **삭제·별도 Build Archive 전환은 실행되지 않았다.**

## 3. PPT형 홈과 전체 영문화 — 2026-08-27

출처: A.

사용자는 세로 스크롤 중심 홈을 PPT 같은 인터랙티브 슬라이드로 바꾸고, 해외 프리랜서 플랫폼에서도 활용할 수 있도록 상단 KR/EN 전환을 요청했다.

구현 결과:

- 홈을 INTRO·POSITION·PRACTICE·METHOD·EXPLORE·CONTACT 6장으로 재구성.
- 휠·키보드·버튼·포인터 스와이프/드래그 및 URL 해시 복원.
- 현재 페이지와 슬라이드를 유지하는 한국어/영어 전환.
- Work·Resume·Writing 목록·상세의 영문 문구와 메타데이터·hreflang·사이트맵·JSON-LD.
- 영문 페이지 제목과 본문 바로가기 문구 보정, 한글 모바일 줄바꿈·터치 영역 개선.

당시 ESLint·타입 검사·프로덕션 빌드가 통과했고 27개 정적 페이지를 생성했다. 데스크톱 1440×900·모바일 390×844와 주요 인터랙션 확인을 보고했다.

이후 사용자가 보고한 `Cannot find module './503.js'` 등의 오류는 생성된 `.next` 청크와 런타임의 불일치로 설명했다. 개발 서버·빌드 동시 실행이 원인일 가능성을 언급했으며, 애플리케이션 코드 오류로 확정하지 않았다.

사용자는 슬라이드 방식의 가독성과 이력서 용도에 만족했고 문구·디자인 수정은 별도로 요청하기로 했다. 이어 **커밋과 푸시를 명시적으로 요청**하여 `develop`에 `f3d799c`를 생성하고 `origin/develop` 푸시 완료를 보고했다. 현재 로컬 HEAD에서도 이 커밋을 확인했다.
